# Dekoy 설치 파일

Dekoy 데스크톱 앱의 **설치 파일 배포처**입니다. 앱은 여기서 새 버전을 확인합니다.
소스 코드는 여기에 없습니다.

## 내려받기

[**최신 버전 받기**](../../releases/latest)

| | |
|---|---|
| 맥 (Apple Silicon) | `Dekoy-x.y.z-arm64.dmg` |
| 윈도우 | `Dekoy-Setup-x.y.z.exe` |

## 맥에서 처음 열 때 「손상되었습니다」가 뜨면

서명 인증서를 아직 받지 않아서입니다. **손상된 것이 아니라 서명이 없는 것뿐입니다.**

1. `Dekoy.app` 을 **응용 프로그램**으로 옮깁니다
2. 터미널에 아래 한 줄을 붙여넣고 Enter

```
xattr -dr com.apple.quarantine /Applications/Dekoy.app
```

3. 앱을 엽니다

앱 안 **설정 → 업데이트**에서도 이 명령을 실제 설치 경로로 만들어 복사할 수 있습니다.

## 업데이트

- **맥** — 새 버전이 나오면 앱이 알려 줍니다. 여기서 받아 같은 자리에 덮어씁니다.
  (인증서를 받으면 자동 업데이트로 바뀝니다)
- **윈도우** — 앱이 스스로 받아 설치합니다.
